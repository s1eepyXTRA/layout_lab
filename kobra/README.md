# Кобра — прототип конструктора дашбордов

Браузерный прототип в стиле Superset: 13 типов графиков, вкладки, текст, нативные фильтры, кросс-фильтрация, синтетические данные продаж DNS, загрузка своих CSV/Excel. Всё хранится в браузере (localStorage, загруженные наборы — IndexedDB).

## Структура

```
src/            исходники: styles.css + JS-модули (порядок сборки: data, engine, ui, viz, app, dashboard, explore, datasets)
vendor/         библиотеки: ECharts 5.5.1, marked 12.0.2, DOMPurify 3.1.6, SheetJS 0.18.5, PapaParse 5.4.1
build.py        сборка в один HTML-файл
build/
  index.html    онлайн-версия: библиотеки с CDN
  kobra.html    офлайн-версия: всё внутри файла, открывается двойным щелчком
service/        начатая серверная часть (не закончена)
  backend/app/core.py   настройки, модели метаданных, пароли, сессии, шифрование подключений
  backend/app/demo/     демо-данные DNS в CSV для загрузки в базу
  tools/export_demo.js  выгрузка демо-данных из src/data.js
```

## Сборка

```bash
python3 build.py           # build/index.html
python3 build.py offline   # build/kobra.html
```

## Ограничения прототипа

- Данные и дашборды живут только в браузере, где открыт файл.
- Выгрузки в файл нет — вместо неё «Посмотреть данные».
- Относительные периоды («последние 12 месяцев») считаются от последней даты в данных — 31.08.2026.
