# Spec Delta

## ADDED Requirements

### Requirement: Объявленная настройка действует

Настройка, объявленная в сервисе, SHALL применяться. Настройка, которая ни на что не влияет, MUST NOT
оставаться в коде: администратор меняет её и считает, что защитился.

#### Scenario: Предел числа строк задан

- **WHEN** администратор задал предел числа строк загружаемого набора
- **THEN** разбор файла останавливается на этом пределе

#### Scenario: Предел не задан

- **WHEN** переменная не задана
- **THEN** действует умолчание сервиса, и оно названо в описании развёртывания
