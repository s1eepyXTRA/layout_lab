# Spec Delta

## ADDED Requirements

### Requirement: Сервис описан документом, а не только чартом

Запуск, настройки, роли образа, порядок миграций и частые отказы SHALL быть описаны в документе
бэкенда. Человек, разворачивающий сервис, MUST NOT читать для этого файлы, написанные для другой
цели.

#### Scenario: Развёртывание первым человеком

- **WHEN** сервис разворачивает тот, кто его не писал
- **THEN** он делает это по документу бэкенда, не открывая исходники и не читая файлы для ассистента

#### Scenario: Отказ при запуске

- **WHEN** сервис не поднялся
- **THEN** в документе есть раздел частых отказов с их признаками и причинами
